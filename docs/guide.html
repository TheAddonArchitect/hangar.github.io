Getting started

Extract the complete portable Windows application ZIP into a permanent folder. Open Hangar.exe. Keep WebView2Loader.dll and the native folder with the application. Download a desktop release rather than a source-code archive when installing the app.

  1. Settings → Simulator & Folders → MSFS installation type: Steam, Microsoft Store / Xbox, or Custom installation.
  2. Choose Primary managed library and any Additional managed libraries.
  3. Select Detect folders; inspect Community destination and optional Community2024 destination.
  4. Validate paths → Save settings → Library → Rescan library.

Attention
Confirm an external drive is connected and all detected destinations are correct before scanning or activating packages. Do not create a folder tree just to match an example.

Library & imports

Browse cards or a table; filter packages and inspect details, tags, notes, activation and compatibility. Use Rescan library after changing files outside Hangar. Import previews stage incoming packages before a commit. Replacements preserve backups. ZIP/RAR/7Z import requires full 7-Zip configured for the desktop app.

  1. Import archives or drop files on Library.
  2. Review staged entries, destination, blockers and replacement acknowledgments.
  3. Commit only the intended packages; inspect the resulting library.

Attention
Marketplace content is read only. Do not treat browser demo activations as disk changes. Review replacement and cleanup actions before applying them.

Flight planning & route scenery

Enter a SimBrief username or Pilot ID and choose Fetch Latest OFP. Hangar reads the latest available operational flight plan; no SimBrief password is requested. Network access and an available OFP are required. Route scenery selection uses known package coordinates and the configured corridor; it cannot prove every enhancement is installed.

  1. Load the OFP and inspect departure, arrival, alternates and route.
  2. Review Route Scenery; inspect the activation preview and resolve blockers.
  3. Export the flight plan as .pln, then import it in the simulator EFB.
Settings → Flight Planning
Settings → Simulator & Folders → MSFS flight plans export folder

Attention
Export writes a flight-plan file. Automatic injection into an in-game EFB is not implemented. Always inspect the imported route in the simulator.

Scenery map

Scenery Map displays geolocated library packages. The Flight Planning map displays the loaded route and fresh live aircraft telemetry when connected. Packages without usable coordinates may not appear. Map tiles need network access. Do not assume the separate map page has every layer or follow control proposed in the draft.

Weather & live tracking

Desktop weather retrieves METAR and TAF for plan airports. Weather interval and refresh-on-load are configurable. The read-only SimConnect bridge supplies position, true heading and altitude; the Microsoft x64 SimConnect.dll is not distributed with Hangar.

  1. Supply the SDK client SimConnect.dll beside HangarSimConnectBridge.exe in the bridge folder, or set SIMCONNECT_DLL to its absolute path before starting Hangar.
  2. Start MSFS and load a flight. In Flight Planning, choose Connect Live Aircraft.
  3. If needed, use Settings → Weather & Tracking → Start Bridge / Stop Bridge. Save bridge-address changes first.
ws://127.0.0.1:8385/
SIMCONNECT_DLL
simconnect-bridge.log

Attention
A bridge socket connection is not proof of a live aircraft position. Waiting, paused or stale data can hide the aircraft. Disconnecting tracking does not stop the bridge. A real MSFS session remains required for end-to-end validation.

Add-on activation & safeguards

The implemented modes are Junctions / symbolic links and Manifest toggling. Direct Copy is not an available activation mode. Supporting packages can be declared or selected through dependency tools. Missing dependencies and cycles block activation. Preferred airport packages guide future activations.

  1. Configure libraries and Community destinations; validate and save.
  2. Review required libraries and preferred airport packages.
  3. Preview profile changes; inspect enable/disable actions and blockers.
  4. Apply the reviewed change and confirm the resulting state.

Attention
Close MSFS before changing active scenery. Changes can be queued while the simulator runs, or blocked when queuing is disabled. An unknown process state is also protected. Do not manually delete links as a recovery shortcut.

Simulator launch

Windows launch methods are Steam, Microsoft Store / Xbox or a chosen executable. Run preflight before launch and minimize-after-launch are available settings. Launch arguments are a JSON array passed directly without a shell. Store launch does not accept arguments.

Settings → Simulator Launch
["-FastLaunch"]

Attention
The argument above is a configuration example; simulator support must be checked on your installation. There is no dedicated Skip Intro Videos or VR-start toggle in this build. Resolve preflight blockers before launch.

SOURCE VERIFIED

Support, diagnostics & recovery

There is no separate Support sidebar page in this build. Use Settings → Application & Diagnostics → Export diagnostics. The implementation describes sanitized settings and counts, excluding personal paths and package files. Review any additional logs or screenshots before sharing them.

  1. Record the action, expected result, actual result and error text.
  2. Export diagnostics from the desktop app.
  3. For bridge issues, inspect simconnect-bridge.log separately.
  4. Use backup/recovery workflows where available; review cleanup candidates before deletion.

Attention
Cleanup is reviewed rather than automatic. Do not delete installed add-ons, original downloads or recovery backups to resolve an unexplained error.

About & updating Hangar

The sidebar displays Hangar v0.7.0. Settings → Application & Diagnostics contains Check for Hangar updates, but this distribution has no automatic update publisher configured. A versioned HTTPS manifest, installer/update flow and separate About/legal page from the draft require implementation.

Attention
