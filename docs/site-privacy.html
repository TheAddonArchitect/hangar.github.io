THE WEBSITE / PRIVACY

A simpler website.
A smaller data footprint.

This page explains this website. It is separate from a privacy policy for the Hangar desktop application.

What this site does

This static site does not include analytics, advertising trackers, forms, accounts, or cookies set by its own code. It does not save your tab or menu choices to browser storage. Fonts, images and scripts are served with the site, rather than loaded from third-party font or analytics services.

GitHub Pages hosting

The site is intended to be hosted on GitHub Pages. GitHub may process IP addresses and request information for hosting and security. Read the GitHub Privacy Statement for its practices.

External links

Links to GitHub releases, repositories and issues take you to GitHub, whose terms and privacy practices apply. Information posted to a public issue may be visible to others. Never post passwords, tokens, private files or vulnerability details in a public issue.

Questions

For general website questions, use the website repository. Security vulnerabilities should be reported privately using a reporting channel published by the project owner.
