03 / GOOD TO KNOW

A few things
before takeoff.

Is Hangar just an add-on manager?

Add-on management is the foundation. Hangar also brings in flight preparation, route scenery selection, airport weather, scenery mapping and live aircraft tracking through a configured bridge.

What do I need to run it?

The current desktop build targets Windows 10/11 x64 with Microsoft Edge WebView2. You’ll need your own supported Microsoft Flight Simulator installation and add-ons. Archive imports need a compatible 7-Zip installation; live tracking needs the Microsoft SimConnect runtime configured as described in the manual.

Does it need an internet connection?

Your library and settings are processed locally. SimBrief flight plans, map tiles, weather and airport dataset downloads require network access and are subject to the providers’ availability and terms.

Does it include a logbook or virtual airline tools?

Flight history, landing statistics and virtual airline/ACARS integrations are planned concepts. They are not implemented in the reviewed 0.7.0 build. Current features and setup requirements are distinguished in the flight manual.

Can I use the weather and routes for real flying?

No. Hangar is for flight simulation and entertainment. Its routes, maps, weather and telemetry are not certified for real-world navigation, dispatch or safety-critical decisions.
